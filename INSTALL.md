# Jarvis Installation

## Ziel

Dieses Setup richtet einen zweiten Windows-PC mit WSL2, Ollama, OpenJarvis, Jarvis Market Briefings und Voice Client ein.

---

## 1. Voraussetzungen Windows

Manuell installieren:

- Windows Terminal
- Python 3.13 oder kompatibel
- WSL2 mit Ubuntu
- NVIDIA Treiber, falls GPU genutzt werden soll

WSL starten:

```bat
wsl
